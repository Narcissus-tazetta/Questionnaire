# Questionnaire

Discord サーバーで、5日に1回ランダムに1人「アンケート担当者」を選ぶ Bot。

## 仕組み

- 抽選は5日ごと（抽選日は `src/config.ts` の `DRAW_CYCLE_ANCHOR` から5日刻み）。当選者は次の抽選まで5日間担当する。
- 担当は事前に募る。`/entry`（および `/auto`）で手を挙げた人が、**次回**の抽選対象になる。
- 抽選日の抽選時刻（日本時間・`/setup` で指定。当選者がまる5日使えるよう `00:00` 推奨）に、対象者から自動で1人選出する。
- 当選者に担当ロールを付与し、告知チャンネルへ結果を投稿する。告知には制作チャンネルの案内を含める。
- 対象者がいない回は抽選を行わず、告知もしない。前回の担当者から担当ロールを外し、その回（5日間）は担当者なしとする。
- 抽選時刻を過ぎて数時間以内に未実施と分かれば、その回の抽選を実行する（それ以降は次回の枠まで待つ。`/draw` なら回の途中でも実行できる）。
- `/reroll` は元の告知メッセージを編集し、新しい担当者に通知を送る。

## コマンド

### 一般

| コマンド | 説明 |
|---|---|
| `/entry` | 次回の抽選に参加登録する |
| `/auto` | 自動参加のオン/オフ。オンの間は解除するまで毎回自動で参加する |
| `/cancel` | 次回分の参加登録を取り消す（`/auto` はオンのまま） |
| `/status` | 自分の参加状態と自動参加の設定を確認する |

### 管理者（サーバー管理権限）

| コマンド | 説明 |
|---|---|
| `/setup` | 抽選時刻・担当ロール・告知チャンネル・制作チャンネルを設定する |
| `/draw` | 今回の抽選を手動実行する |
| `/reroll` | 今回の抽選をやり直す |
| `/participants` | 次回の抽選の参加者一覧を表示する |

## 文言の編集

Bot が発言・返信する文言はすべて [`src/messages.ts`](src/messages.ts) にまとまっている。
ダブルクオートで囲まれた日本語部分だけを書き換え、デプロイすると反映される。
コマンド一覧の説明文（`commands:`）を変えた場合は `bun run register` も実行する。

## 技術

Cloudflare Workers(HTTP Interactions)+ D1 + Durable Object アラーム。TypeScript / Bun。

```bash
bun install
bun test
```
