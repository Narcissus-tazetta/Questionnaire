# Questionnaire

Discord サーバーで、毎日ランダムに1人「アンケート担当者」を選ぶ Bot。

## 仕組み

- 参加者を募り、抽選時刻（日本時間・`/setup` で指定）に自動で1人選出する。
- 当選者に担当ロールを付与し、告知チャンネルへ結果を投稿する。告知には制作チャンネルの案内を含める。
- 前日の担当者は翌日の抽選から除外する（最低1日は間隔を空ける）。
- 参加者がいない場合は抽選せず、前日の担当者がそのまま継続する。
- `/reroll` は元の告知メッセージを編集し、新しい担当者に通知を送る。

## コマンド

### 一般

| コマンド | 説明 |
|---|---|
| `/entry` | 本日の抽選に参加する |
| `/auto` | 自動参加のオン/オフ。オンの間は解除するまで毎日自動で参加する |
| `/cancel` | 本日の参加を取り消す（`/auto` はオンのまま） |
| `/status` | 自分の参加状態と自動参加の設定を確認する |

### 管理者（サーバー管理権限）

| コマンド | 説明 |
|---|---|
| `/setup` | 抽選時刻・担当ロール・告知チャンネル・制作チャンネルを設定する |
| `/draw` | 本日の抽選を手動実行する |
| `/reroll` | 本日の抽選をやり直す |
| `/participants` | 本日の参加者一覧を表示する |

## 文言の編集

Bot が発言・返信する文言はすべて [`src/messages.ts`](src/messages.ts) にまとまっている。
ダブルクオートで囲まれた日本語部分だけを書き換え、デプロイすると反映される。
コマンド一覧の説明文（`commands:`）を変えた場合は `bun run register` も実行する。

## 技術

Cloudflare Workers(HTTP Interactions)+ D1 + Durable Object アラーム。TypeScript / Bun。

```bash
bun install
bun test
```
